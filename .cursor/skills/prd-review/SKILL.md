# PRD Review

## 目标

在冻结前找出遗漏与矛盾；**默认先出清单**，用户确认后再改文件。

## 输入

- `PRD review: <功能>` 或 `PRD review: <产品>`（全产品轻量对齐）
- 相关 prd + spec + `00-overview.md`

## 步骤

1. 对照检查单（逐项打 ✓/✗）：
   - 主流程是否闭环
   - 异常：未登录、重复操作、非法输入、超时、限流
   - 权限：谁能在什么状态做什么
   - 数据：创建/更新/删除与保留策略
   - 与 L0 术语、全局约束是否冲突
   - spec 与 md 是否一致
   - 验收是否可测试；是否有无法实现的 AC
2. 输出结构化 **审查报告**：
   - **阻塞项**（freeze 前必须解决）
   - **建议项**
   - **非目标检查**（是否偷偷塞了 scope.out 里的内容）
3. 若用户说「按清单改」，再进入 define/spec 修改；否则不改文件

## Freeze 门控

- **未在本产品做过 review 的功能，不得执行 `PRD freeze`**
- 用户声明「已在别会话 review」时，要求简述已解决的阻塞项，否则仍建议 quick review

## 建议下一步

解决阻塞项 → `PRD freeze`
