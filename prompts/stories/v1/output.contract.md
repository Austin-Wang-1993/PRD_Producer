## 硬性指标

| 指标 | 阈值 |
|------|------|
| 故事 ID | US-{三位数字}，唯一 |
| 句式 | 「作为…，我想要…，以便…」 |
| 溯源 | 功能ID ∈ 功能清单；映射步骤 ∈ BRD §5.2 |
| 覆盖 | 每个 MVP 功能 ≥1 条故事 |
| 禁止 | 无来源页面/功能 |

## 优先级

- MVP：首期必做
- P1：紧随其后
- P2：可不做
