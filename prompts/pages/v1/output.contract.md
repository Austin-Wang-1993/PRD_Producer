## 2. 页面总览

## 硬性指标

| 指标 | 阈值 |
|------|------|
| 页面覆盖 | BRD §5.4 每个 ID 出现在 §2（或说明省略原因） |
| 功能 ID | 格式 `P{page}-F{nn}`，如 P02-F01 |
| 映射步骤 | 每个功能必有「映射步骤」，对应 BRD §5.2 步骤号 |
| 孤儿 | 映射检查表中无未覆盖步骤、无无依据页面 |

## 功能描述

- 一句「谁在哪做什么 → 系统什么反应」
- 不写 API、不写组件库
