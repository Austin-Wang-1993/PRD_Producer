# 质检清单 — BRD

质检时对 `docs/BRD.md` 逐项检查。每项标注：`pass` | `fail` | `warn`，fail 必须写入问题清单并阻塞放行。

---

## A. 格式与章节（阻塞）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| BRD-F01 | 文档标题 | 含 `# BRD` 与产品名 |
| BRD-F02 | 元信息表 | 含版本、状态字段 |
| BRD-F03 | §1 背景与目标 | 含 1.1 需求背景、1.2 产品目标、1.4 非目标 |
| BRD-F04 | §2 用户与场景 | 至少 1 个用户角色、3 个场景（或说明本期仅 1 场景并给理由） |
| BRD-F05 | §3 业务范围 | 含 In scope 与 Out of scope |
| BRD-F06 | §4 业务主流程 | 有编号步骤或列表，非空 |
| BRD-F07 | §5 用户主流程 | 含 5.1 总览、5.2 主路径表、5.3 分支、5.4 页面索引 |
| BRD-F08 | §6–§9 | 含业务规则、成功指标、待决问题、变更记录 |

## B. §5 用户主流程（阻塞 · 核心）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| BRD-F09 | 主路径步数 | 5.2 表格 ≥ 5 行（有效步骤，非占位） |
| BRD-F10 | 每步有页面/触点 | 5.2 每行「页面/触点」列非空且为具体 ID 或名称（非 TBD） |
| BRD-F11 | 分支/异常 | 5.3 ≥ 2 条分支，或 5.3 明确写「本期无分支」+ 1.4 非目标呼应 |
| BRD-F12 | 页面索引 | 5.4 表格 ≥ 1 行；页面 ID 与 5.2 中出现的触点一致 |
| BRD-F13 | 可枚举性自问 | 仅凭 §5 能列出 ≥80% 预期页面；否则 fail（备注：需补充澄清） |

## C. 内容质量（warn / 可升级 fail）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| BRD-F14 | 目标可衡量 | 1.2 或 1.3 含可观测指标，非「提升体验」空泛句 |
| BRD-F15 | 非目标非空 | 1.4 ≥ 3 条具体不做项 |
| BRD-F16 | 待决问题 | §8 无阻塞性 TBD（关键流程、角色未定则 fail） |
| BRD-F17 | 前后一致 | §4 业务流与 §5 产品内流不矛盾 |
| BRD-F18 | 无实现细节越界 | 不出现具体 API 路径、SQL、组件库选型（除非写在约束且必要） |

## D. 输出问题清单格式

```yaml
artifact: brd
round: <n>
blocking:
  - id: BRD-F09
    location: "§5.2"
    issue: "主路径仅 3 步"
    suggestion: "补充从进入到完成核心目标的完整步骤"
warnings: []
```
