# 质检清单 — 用户故事清单

对 `docs/用户故事清单.md` 检查。依赖：`docs/BRD.md`、`docs/页面功能清单.md` 最新版。

---

## A. 格式（阻塞）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| ST-F01 | 文档标题 | `# 用户故事清单` |
| ST-F02 | 编写约定 | 说明角色、故事句式、优先级定义 |
| ST-F03 | 总表字段 | 每行含：页面、功能ID、故事ID、用户故事、映射步骤、优先级 |
| ST-F04 | 故事 ID 唯一 | US-xxx 无重复 |
| ST-F05 | 覆盖率自检 | 文档末有自检表或说明 |
| ST-F06 | 变更记录 | 有版本 |

## B. 溯源（阻塞）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| ST-F07 | 功能 ID 存在 | 每条故事的 功能ID 在功能清单中存在 |
| ST-F08 | 页面 存在 | 每条故事的 页面 在功能清单总览中存在 |
| ST-F09 | 映射步骤 | 每条有映射步骤，且该步骤在 BRD §5.2 存在 |
| ST-F10 | 无编造页面/功能 | 无功能清单未定义的 P-xx / Fxx |
| ST-F11 | 核心功能覆盖 | 功能清单中每个 MVP 功能 ≥ 1 条用户故事 |

## C. 故事质量（warn）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| ST-F12 | 句式完整 | 符合「作为…我想要…以便…」或等价三段 |
| ST-F13 | 粒度 | 单故事可在一个迭代实现，过大则 warn |
| ST-F14 | 异常分支 | BRD §5.3 主要分支在故事中至少有 1 条体现（或说明由多条故事覆盖） |

## D. Epic（可选）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| ST-F15 | 跨页面 epic | 若存在编排类 epic，与 BRD 规则（如建库时机）一致 |
