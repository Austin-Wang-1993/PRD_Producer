# 质检清单 — 页面&功能清单

对 `docs/页面功能清单.md` 检查。依赖：同项目 `docs/BRD.md` 已定稿或提供最新版。

---

## A. 格式（阻塞）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| PG-F01 | 文档标题 | `# 页面 & 功能清单` 或等价 |
| PG-F02 | 依据说明 | 标明依据 BRD 版本或日期 |
| PG-F03 | 页面总览表 | 含 页面ID、页面名称、路由建议、关联 BRD 步骤 |
| PG-F04 | 页面功能明细 | 每个页面 ID 有独立小节与功能表 |
| PG-F05 | 功能表字段 | 每功能含：功能ID、功能名称、描述、映射步骤 |
| PG-F06 | 映射检查节 | 含「与 BRD 主流程映射检查」表或等价 |
| PG-F07 | 变更记录 | 有版本与日期 |

## B. 与 BRD 对齐（阻塞）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| PG-F08 | BRD §5.4 覆盖 | BRD 5.4 每个页面 ID 在总览表出现（或说明刻意合并/省略理由） |
| PG-F09 | 无孤儿页面 | 功能清单中每个页面 ID 在 BRD §5.2/5.4 有依据 |
| PG-F10 | 无孤儿步骤 | BRD §5.2 每步在映射检查表中有对应功能或说明「系统后台/无 UI」 |
| PG-F11 | 页面 ID 一致 | 全文页面 ID 命名与 BRD 5.4 一致（P-01 等），无自造未定义 ID |

## C. 功能粒度（warn / 可升级 fail）

| ID | 检查项 | 通过标准 |
|----|--------|----------|
| PG-F12 | 每页功能数 | 每页 ≥ 1 个功能；核心页（工作台等）≥ 5 个功能 |
| PG-F13 | 功能可验收 | 描述为可观察行为，非「优化体验」 |
| PG-F14 | 导航关系 | 有页面关系说明或导航图（MVP 可简表） |

## D. 问题清单格式

```yaml
artifact: pages
round: <n>
blocking: []
warnings: []
upstream_ref: brd@v<version>
```
