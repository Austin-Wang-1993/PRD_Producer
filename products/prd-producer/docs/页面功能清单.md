## 1. 文档说明

- 本文档枚举 **PRD Producer** 全部页面及每页功能点。
- 功能均映射 **BRD §5.2 步骤** 与 **§5.4 页面 ID**。
- 智能体解耦：通过 **P-02 工作台 Tab** 切换，无自动跳转。

| 页面ID | 页面名称 | 路由建议 | 关联 BRD 步骤 |

## 3. 页面功能明细

### P-01 项目列表

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P01-F01 | 展示项目卡片 | 标题、创建时间、三文档状态徽章（澄清中/质检中/待确认/已定稿） | 1 |
| P01-F02 | 新建项目 | 输入标题、描述；创建后跳转 P-02，初始无 GitHub | 2 |
| P01-F03 | 进入项目 | 打开 P-02 | 1 |
| P01-F04 | 删除项目 | 二次确认；若已建库提示 GitHub 需手动删仓 | 1 |
| P01-F05 | 打开 GitHub | 已建库项目显示外链 | 13 |

### P-02 项目工作台（核心）

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P02-F01 | 顶栏阶段/文档状态 | 展示当前智能体、当前文档子状态 | 3–12 |
| P02-F02 | 智能体 Tab 切换 | BRD \| 功能清单 \| 用户故事；切换保留各自会话历史 | 3,8,9,10 |
| P02-F03 | 澄清聊天区 | 与当前 Tab 对应智能体对话；支持用户随时发消息 | 3,8,9 |
| P02-F04 | 开始编写通知 | 消息类型：智能体停止追问、开始编写；醒目标式 | 4 |
| P02-F05 | 笔记侧栏 | 展示当前智能体澄清笔记（只读/同步刷新） | 3 |
| P02-F06 | 文档预览切换 | BRD / 功能清单 / 用户故事 只读预览（拉取最新稿） | 6,8,9 |
| P02-F07 | 提交质检 | 编写完成后进入质检（可自动触发） | 5 |
| P02-F08 | 系统对话区（质检） | 折叠区：质检↔编写轮次；展开可看详情 | 5 |
| P02-F09 | 质检协助入口 | 当 `qa_need_user`：主聊天区提示原因，用户回复 | B2 |
| P02-F10 | 上游过期提示条 | BRD 变更后，在功能清单/用户故事 Tab 显示橙条 | B5 |
| P02-F11 | 子 Tab：过程日志 | 时间线 + 筛选（智能体/事件类型/文档） | 11 |
| P02-F12 | 子 Tab：观察记录 | 只读 observer 内容 | 12 |
| P02-F13 | 进入确认页 | 质检通过后显示「待你确认」；跳转 P-03/P-05/P-06 | 6,8,9 |
| P02-F14 | 软依赖提示 | 打开功能清单无 BRD 定稿、打开故事无清单定稿时黄条 | 8,9 |

### P-03 BRD 确认

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P03-F01 | BRD 全文预览 | 默认展开 §5 用户主流程 | 6 |
| P03-F02 | 确认通过 | 状态→`brd_confirmed`；出现 P-04 入口 | 6 |
| P03-F03 | 要求修改 | 回到 P-02 BRD 聊天，带修改意见 | B1 |
| P03-F04 | 继续澄清 | 回到澄清，不视为确认 | B1 |
| P03-F05 | 版本号展示 | 如 v1.0 / 修订 v1.1 | 6 |

### P-04 授权创建 GitHub（模态）

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P04-F01 | 展示将创建字段 | name、description、visibility；由智能体生成，用户可改 | 7 |
| P04-F02 | 授权并创建 | 调 API；loading；成功/失败 toast | 7 |
| P04-F03 | 创建成功通知 | 仓库 URL、首次 commit 摘要 | 7 |
| P04-F04 | 取消 | 保持 `brd_confirmed` 未建库 | 7 |

### P-05 功能清单确认

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P05-F01 | 功能清单全文预览 | 含页面表、每页功能表、流程映射列 | 8 |
| P05-F02 | 确认通过 | 定稿 push `docs/页面功能清单.md` | 8 |
| P05-F03 | 要求修改 / 继续澄清 | 回 P-02 功能清单 Tab | 8 |
| P05-F04 | 映射检查摘要 | 展示是否存在孤儿页面/孤儿步骤（可来自质检结果） | 8 |

### P-06 用户故事确认

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P06-F01 | 用户故事表预览 | 表格：页面、功能ID、故事ID、故事描述、映射步骤 | 9 |
| P06-F02 | 确认通过 | 定稿 push `docs/用户故事清单.md` | 9 |
| P06-F03 | 要求修改 / 继续澄清 | 回 P-02 用户故事 Tab | 9 |
| P06-F04 | 回溯检查摘要 | 无来源页面/功能的故事条数 | 9 |

### P-07 设置

| 功能ID | 功能名称 | 描述 | 映射步骤 |
|--------|----------|------|----------|
| P07-F01 | GitHub 连接 | OAuth 或 PAT；显示连接状态 | 7 |
| P07-F02 | 默认仓库可见性 | private / public | 7 |
| P07-F03 | 仓库命名规则说明 | `prd-{slug}-{id}` | 7 |
| P07-F04 | LLM API 配置 | 模型、Key（后端调用） | 3 |
